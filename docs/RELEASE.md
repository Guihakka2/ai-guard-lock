# AI Guard Lock 1.0.0 配布検証

## 配布物

- `dist/AI-Guard-Lock-1.0.0-win-x64.zip`：Intel/AMD、Windows 11。
- `dist/AI-Guard-Lock-1.0.0-win-arm64.zip`：ARM64、Windows 11。
- 各ZIPの隣にSHA-256ファイル、展開先にEXEのSHA256SUMS.txtを配置。
- .NET 10.0.14の自己完結型・単一EXE。ネイティブライブラリは起動時に一時フォルダーへ展開。トリミングは無効。
- 日本語ガイド、デスクトップショートカット作成用CMD/PowerShell、ランタイムのライセンス・第三者告知を同梱。
- 署名なし。インストーラー、自動起動登録、サービス、管理者権限の要求はなし。

## 確認結果

- アイコン追加後のReleaseビルド：警告0、エラー0。既存60チェック成功。
- x64、ARM64の自己完結型単一EXEの発行成功。
- PE Machineはx64が0x8664、ARM64が0xAA64。
- EXEのSHA-256は同梱ファイルと一致。
- x64 ZIPを日本語を含む別フォルダーへ展開して起動。DOTNET_ROOT/DOTNET_ROOT_X64を存在しないパス、DOTNET_MULTILEVEL_LOOKUPを0にして設定画面の起動を確認。
- WPFネイティブモジュールがユーザーの一時フォルダー `.net/AiGuardLock/...` から読み込まれることを確認。
- 設定画面の通常終了を確認。認証・画面カバーは起動時に自動開始しない。
- 発行済みEXEからアイコンを抽出して確認。マルチサイズICOのシールドと鍵穴が組み込まれている。
- このPCのデスクトップに、配布版x64 EXEを指すショートカットを作成した。

## 残る実機確認

- 本当の別PCでの実行と、そのPCのWindows Hello認証。
- ARM64実機での起動・認証（今回の環境はx64のため未実施）。
- 会社の配布・アプリ実行ポリシーとの適合。

現在の配布版は主画面のみ対応で、OSのセキュリティ境界にはならない。Windows Helloの成功は本人確認の結果であり、タスク切替やプロセス終了を防ぐ意味ではない。

## macOS・Linuxプレビュー

linux-x64、linux-arm64、osx-arm64、osx-x64を自己完結型で発行。Windows上で共通コード19チェックとネイティブウィンドウ4チェックを通過。実機確認は未実施。Mac版は未署名・未公証で、通常配布にはMac上での署名・公証が必要です。Linux版はX11/XWaylandと合成処理を想定します。アプリ専用PINのみ対応し、Touch ID・PAMは使用しません。

アーカイブに実行権限、MacのInfo.plist・ICNS、依存ライブラリのライセンス・告知、ファイル単位とアーカイブのSHA-256を同梱しています。

## 1.0.1 公開前修正版

Core DLLに残っていた開発PCのPDBパスを除去。Releaseのデバッグ情報無効化・ソースパス置換・OS/CPUごとの独立ビルド出力を使用。ライセンス収集も隔離された実際の復元結果を参照します。6配布物のユーザー名・機微ファイル検査0件、SHA-256一致、Windows60チェック・共通19チェック成功。詳細はSECURITY-REVIEW-JA.mdを参照。
