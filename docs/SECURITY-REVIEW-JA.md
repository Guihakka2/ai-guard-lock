## 見つかった問題と修正

1. 1.0.0のmacOS/Linux配布物にあるAiGuardLock.Core.dllのデバッグディレクトリに、ビルドPCのユーザーフォルダー名が含まれていました。秘密鍵や接続情報ではありませんが、公開物の個人情報混入です。Releaseのデバッグ情報を無効化し、ソースパスを`/_/`へ置き換え、配布ごとに別のビルドディレクトリを使って1.0.1を作成します。
2. 配布ビルドの隔離後もライセンス収集が従来のobjフォルダーを参照する問題を修正し、実際に使用したproject.assets.jsonを明示的に渡すようにしました。
3. NuGetの全依存監査を明示し、Dependabotの更新確認設定とSECURITY.mdを追加しました。
